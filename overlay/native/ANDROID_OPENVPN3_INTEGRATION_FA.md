# OpenVPN 3 source review and integration decision

## Exact upstream revision selected
- Repository: https://github.com/OpenVPN/openvpn3
- Commit: `0abc8313b8fe5f63dbebc10d53094952957845d9` (2026-10-29)
- The CI workflow checks out this exact commit detached and verifies the resulting SHA. This makes the reviewed source reproducible.

## Relevant upstream API
- Public client API: `client/ovpncli.hpp`
- Main implementation: `client/ovpncli.cpp`
- Java/SWIG interface: `client/ovpncli.i`
- Android-specific helper currently in upstream tree: `javacli/android/cpu.cpp`
- CMake project uses C++20 and includes multiple platform targets. It is not safe to assume the root CMake project can be dropped unchanged into an Android NDK build.

## Integration implications
The official developer guide documents `ClientAPI::OpenVPNClient`, `TunBuilderBase`, `LogReceiver`, and a worker-thread connection lifecycle. On Android/iOS the core uses the TunBuilder abstraction unless an external TUN factory is selected. RahYabVPN must implement the Android callback adapter and JNI/session lifetime correctly.

## Why this commit does not yet vendor or link the full core
The repository includes dependencies and platform-specific CMake configuration. Before adding the full source tree to the APK build, we must map its dependency targets, OpenSSL/crypto selection, Android ABI flags, and license notices. A partial copy or a stub JNI library would create a misleading APK and is deliberately avoided.

## License
Upstream LICENSE.md offers MPL-2.0 or AGPL-3.0-only with an OpenSSL exception. The project must select a compliant distribution path and ship the required notices/source availability before public distribution. This is a release requirement, not a runtime feature.

## Current status
The CI workflow now verifies and archives the exact upstream API/header and license material. It still does not link OpenVPN 3 into the Android application. The APK generated by this workflow remains a scaffold until NDK/CMake/JNI/TunBuilder integration and on-device traffic tests pass.
