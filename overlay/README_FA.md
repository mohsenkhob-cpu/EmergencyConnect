# RahYabVPN overlay

این پوشه برای فایل‌های نگهداری‌شده خارج از ZIP پایه است. گردش کار شاخه v2 پس از استخراج ZIP، این پوشه را روی پروژه استخراج‌شده کپی می‌کند. بنابراین می‌توان فایل‌های جدید Android/native را بدون بازسازی دستی ZIP وارد build کرد.

در این مرحله فقط زیرساخت overlay و مستندات ادغام ثبت شده‌اند؛ موتور OpenVPN 3 هنوز پیاده‌سازی نشده است.
