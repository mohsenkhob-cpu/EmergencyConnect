# راه‌یاب VPN — شاخه توسعه rahyab-next

این مخزن شامل برنامه Android راه‌یاب، دریافت‌کنندهٔ فهرست عمومی VPN Gate، سرویس‌های موتورهای VPN و مسیر آزمایشی OpenVPN 3 است.

## قابلیت‌های قابل مشاهده در سورس فعلی

- دریافت پروفایل‌های عمومی OpenVPN از API رسمی VPN Gate.
- اعتبارسنجی ساختار پروفایل و حذف موارد نامعتبر یا تکراری.
- بسته‌بندی کتابخانهٔ بومی OpenVPN 3 برای ABI مربوط به ARM64 و بررسی نمادهای JNI در CI.
- مسیر آزمایشی نشست OpenVPN 3 از طریق JNI، همراه با اتصال callbackهای سرویس Android و مدیریت چرخهٔ عمر.
- منطق آزمایشی انتخاب هوشمند: بررسی حداکثر چهار نامزد، سنجش عبور ترافیک HTTPS و IP خروجی، مقایسهٔ کیفیت و امتحان دوبارهٔ گزینهٔ برتر.
- ثبت رویدادهای تشخیصی برای بررسی خطاهای جست‌وجو و چرخهٔ اتصال.

## هشدار مهم: اتصال واقعی هنوز تأیید نشده است

فعال بودن مسیر نشست آزمایشی یا موفقیت ساخت APK، اثبات نمی‌کند که اتصال VPN روی گوشی برقرار می‌شود یا تمام ترافیک از تونل عبور می‌کند. آزمون‌های CI فقط ساخت، آزمون‌های واحد، وجود کتابخانه و قراردادهای JNI/TUN را بررسی می‌کنند.

تا زمانی که آزمایش دستگاه واقعی موفق نشده باشد، موارد زیر تأییدشده محسوب نمی‌شوند:
- اتصال واقعی و پایدار OpenVPN یا sing-box روی دستگاه.
- تغییر IP خروجی و عبور HTTPS از داخل تونل.
- نبود نشت DNS یا IPv6.
- عملکرد درست هنگام قطع شبکه، توقف سرویس و جابه‌جایی خودکار سرور.

## وضعیت موتور و منابع سرور

VPN Gate یک منبع عمومی متشکل از رله‌های داوطلبانه است. رایگان بودن به معنی امن، خصوصی یا پایدار بودن نیست. اپراتور هر رله مستقل است و نباید برای اطلاعات حساس به آن اعتماد کرد.

در پروژه کد و وابستگی‌های مربوط به موتورهای دیگر نیز وجود دارد؛ اما وجود یک سرویس یا کتابخانه به‌تنهایی به معنی یکپارچگی کامل، پشتیبانی عملی همهٔ پروتکل‌ها یا اتصال تأییدشده نیست. هر موتور باید جداگانه روی دستگاه آزمایش شود.

## مسیرهای باقی‌مانده

1. آزمون عملی شروع/توقف نشست و چرخهٔ عمر سرویس روی گوشی Android واقعی.
2. تأیید عبور IPv4 و HTTPS و تغییر IP خروجی.
3. آزمون DNS و IPv6 leak و رفتار fail-closed هنگام افت تونل.
4. آزمون پایداری، قطع و وصل شبکه و جابه‌جایی خودکار سرور.
5. بررسی سازگاری واقعی موتورهای OpenVPN 3، sing-box و WireGuard با پروفایل‌های مربوط.
6. تکمیل و بازبینی رابط کاربری و گزارش عیب‌یابی فارسی.
