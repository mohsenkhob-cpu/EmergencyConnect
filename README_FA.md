# راه‌یاب VPN — نسخه توسعه ۲

این مخزن شامل برنامه Android راه‌یاب VPN و لایه نگهداری‌شده برای ساخت هسته OpenVPN 3 است.

## قابلیت‌های موجود

- دریافت فهرست عمومی سرورهای VPN Gate.
- مرتب‌سازی سرورها بر اساس سرعت گزارش‌شده.
- بررسی نحوی پروفایل با parser هسته OpenVPN 3.
- انتقال فایل پروفایل به برنامه OpenVPN for Android برای اتصال خارجی.
- ساخت کتابخانه بومی OpenVPN 3 و بسته‌بندی آن در APK آزمایشی.
- سرویس Android و آداپتور TUN در حد زیرساخت اولیه.

## محدودیت مهم: هنوز VPN مستقل نیست

**وجود هسته OpenVPN 3 در APK به معنی آماده بودن اتصال داخلی نیست.** مدیریت کامل نشست JNI هنوز تکمیل نشده است: شروع/توقف واقعی کلاینت، thread اجرایی امن، ارسال رویدادها به Android، چرخه عمر TUN، و آزمون عبور ترافیک روی دستگاه باقی مانده‌اند. در نتیجه `OpenVpn3Bridge.isAvailable()` عمداً false است و برنامه نباید وضعیت اتصال مستقل را نمایش دهد.

برای استفاده از قابلیت فعلی، پروفایل انتخابی به OpenVPN for Android منتقل می‌شود. موفقیت ساخت APK یا آزمایش رمزنگاری به معنی اتصال یا عبور ترافیک نیست.

## دریافت APK آزمایشی

در GitHub به بخش Actions بروید، آخرین اجرای موفق `Build RahYabVPN APK` را باز کنید و Artifact با نام `RahYabVPN-v2-APK` را دریافت کنید.

## مسیر تکمیل

1. پیاده‌سازی مدیریت نشست JNI با مالکیت روشن کلاینت و worker.
2. اتصال callbackهای رویداد و گزارش خطا به سرویس Android.
3. مدیریت idempotent برای توقف، لغو مجوز و نابودی سرویس.
4. آزمون TUN، حفاظت socket، DNS و مسیرها.
5. آزمون اتصال واقعی، عبور ترافیک و قطع/وصل شبکه روی دستگاه‌های Android.

جزئیات در `overlay/README_FA.md` آمده است.

## امنیت و حریم خصوصی

سرورهای عمومی داوطلبانه‌اند و ممکن است ناپایدار یا نامطمئن باشند. اپراتور سرور می‌تواند فراداده اتصال را ببیند و در برخی شرایط به ترافیک رمزنگاری‌نشده دسترسی داشته باشد. برای بانکداری و اطلاعات حساس از سرورهای ناشناس استفاده نکنید.
