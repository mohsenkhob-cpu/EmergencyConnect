# بررسی مقایسه‌ای ۲۰ VPN برای طراحی راه‌یاب
تاریخ تهیه: ۵ نوامبر ۲۰۲۶

این سند یک بررسی اولیه از محصولات شناخته‌شده و گزینه‌های رایگان است؛ **آزمون آزمایشگاهی ۲۰ اپلیکیشن روی یک گوشی و یک شبکه انجام نشده است**. بنابراین سرعت، پایداری و امنیت عملی آن‌ها در ایران را نمی‌توان از رتبه‌بندی وب‌سایت‌ها نتیجه گرفت. شرایط طرح رایگان نیز ممکن است تغییر کند.

## معیارهای مقایسه
- مدل رایگان و محدودیت مصرف/سرور
- شفافیت مالکیت، سیاست ثبت داده و ممیزی مستقل
- پروتکل‌ها و روش‌های مقابله با مسدودسازی
- کلید قطع اضطراری، محافظت DNS و IPv6
- منبع‌باز بودن اجزا و امکان بررسی مستقل
- کیفیت اتصال در شبکه‌های مختلف و امکان بازیابی پس از قطع
- تبلیغات، ردیاب‌ها، مجوزهای اندروید و مدل درآمد

## نتیجه‌های قابل استفاده برای راه‌یاب
1. **سرور رایگان ناشناس را معادل سرور امن ندانیم.** VPN Gate و دیگر رله‌های عمومی می‌توانند توسط اشخاص ثالث اداره شوند؛ کاربر باید منبع و سطح اعتماد را ببیند.
2. **اتصال را فقط پس از عبور واقعی اینترنت تأیید کنیم.** بالا آمدن سرویس یا ایجاد TUN به‌تنهایی کافی نیست.
3. **محافظت نشت DNS و IPv6 و رفتار kill switch باید آزمون مستقل داشته باشد.**
4. **در شبکه‌های ناپایدار، بازیابی و تعویض شبکه مهم‌تر از سرعت لحظه‌ای است.**
5. **اطلاعات حساس، کلیدها و پروفایل‌های خصوصی نباید وارد گزارش عیب‌یابی شوند.**
6. **تبلیغات و درآمدزایی نباید با فروش داده یا اشتراک‌گذاری پهنای باند کاربر انجام شود.**
