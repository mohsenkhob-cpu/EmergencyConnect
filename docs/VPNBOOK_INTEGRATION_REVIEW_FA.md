# ارزیابی فنی منبع VPNBook برای راه‌یاب

تاریخ بررسی: 2026-11-05

## نتیجه اجرایی

VPNBook نامزد قابل بررسی برای منبع دوم است، اما در این مرحله نباید آن را به‌عنوان provider اتصال خودکار فعال کنیم. صفحه رسمی وضعیت، بار نسبی و نام میزبان سرورها را نمایش می‌دهد؛ این اطلاعات به‌تنهایی فایل WireGuard یا OpenVPN قابل اتصال تولید نمی‌کند.

## اطلاعات تأییدشده از صفحات رسمی

- صفحه وضعیت رسمی: https://static.vpnbook.com/status
- صفحه تولید WireGuard: https://static.vpnbook.com/freevpn/wireguard-vpn
- صفحه اصلی: https://www.vpnbook.com/

صفحه رسمی WireGuard در زمان بررسی، ده endpoint را در پنج کشور فهرست می‌کند و پورت‌های UDP برابر 443، 80، 123 و 25018 را ارائه می‌دهد.
صفحه تولید کانفیگ اعلام می‌کند کاربر باید شرایط را بپذیرد و کانفیگ اختصاصی تولید کند؛ هر کانفیگ برای یک دستگاه هم‌زمان و دارای عمر اعلامی هفت روز است.
صفحه اصلی در خبر سرویس به session چهل‌وهشت‌ساعته اشاره کرده است؛ به دلیل این ناسازگاری، زمان انقضا باید در زمان تولید واقعی و از خود صفحه تولید بررسی شود و نباید در کد به‌صورت ثابت فرض شود.
صفحه وضعیت می‌گوید بار سرورها هر پنج دقیقه به‌روزرسانی می‌شود؛ این فقط سیگنال انتخاب اولیه است و اتصال یا سرعت تونل را ثابت نمی‌کند.

## موانع فنی برای خودکارسازی کامل

1. صفحه تولید WireGuard نیازمند پذیرش شرایط و یک مرحله بررسی/تأیید است. تا زمانی که قرارداد رسمی و پایدار برای API تولید کانفیگ مستند نشده، نباید فرم وب را با درخواست‌های حدسی یا دورزدن کنترل‌ها خودکارسازی کنیم.
2. فایل WireGuard شامل کلید خصوصی دستگاه است. این کلید نباید به گزارش تشخیصی، لاگ، رابط عمومی یا مخزن Git وارد شود.
3. کانفیگ موقت باید تاریخ تولید و زمان انقضای تأییدشده داشته باشد و پیش از اتصال، ساختار، DNS، AllowedIPs، endpoint و کلیدها اعتبارسنجی شوند.
4. صفحه وضعیت فقط برای رتبه‌بندی اولیه مناسب است؛ پس از دریافت کانفیگ، اتصال واقعی، handshake، HTTPS از تونل، IP خروجی، DNS و IPv6 باید جداگانه آزمایش شوند.
5. OpenVPN VPNBook از اطلاعات ورود عمومیِ قابل‌تغییر استفاده می‌کند. رمز مشترک نباید در APK یا مخزن hard-code شود و دریافت/نگهداری خودکار آن بدون مسیر رسمی و امن نباید پیاده‌سازی شود.
6. رایگان بودن این منبع به معنی ناشناس‌بودن یا مناسب‌بودن برای اطلاعات حساس نیست. برچسب اعتماد و هشدار حریم خصوصی باید کنار آن نمایش داده شود.

## تصمیم پیاده‌سازی

- در نسخه فعلی، VPNBook فقط در فهرست منابع مورد ارزیابی باقی می‌ماند؛ هنوز به انتخاب خودکار و چرخه اتصال اضافه نمی‌شود.
- گام مجاز بعدی، ساخت یک parser محدود و آزمون‌پذیر برای صفحه وضعیت رسمی است؛ این parser فقط نام میزبان، پروتکل، وضعیت و زمان آخرین گزارش را استخراج می‌کند و هرگز آن را «سرور متصل» معرفی نمی‌کند.
- اتصال WireGuard فقط پس از مشخص‌شدن مسیر رسمی تولید/واردکردن کانفیگ و حفاظت از کلید خصوصی قابل فعال‌سازی است.
- PPTP به دلیل قدیمی‌بودن و سطح امنیت پایین وارد موتور هوشمند نمی‌شود.
