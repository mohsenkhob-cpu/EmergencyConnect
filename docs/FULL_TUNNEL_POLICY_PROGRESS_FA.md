# گزارش پیشرفت سیاست تونل کامل راه‌یاب

تاریخ: 2026-11-05

## کنترل‌های تازه
- کلاس `FullTunnelPolicy` پیش از ایجاد TUN اجرا می‌شود.
- هر خانواده آدرس فعال باید مسیر پیش‌فرض همان خانواده را داشته باشد: IPv4 برابر `0.0.0.0/0` و IPv6 برابر `::/0`.
- پروفایل فاقد DNS ارائه‌شده برای VPN رد می‌شود تا DNS شبکه اصلی به‌صورت ناخواسته استفاده نشود.
- مسیرهای مستثناشده در حالت full-tunnel رد می‌شوند.
- آزمون‌های JVM برای IPv4، dual-stack، مسیر ناقص، DNS غایب و excluded route اضافه شده‌اند.

## رابط
- دکمه اصلی به «اتصال هوشمند» کوتاه شده است.
- ورود فایل WireGuard، JSON sing-box، لینک‌های VLESS/VMess/Trojan و سرورهای ذخیره‌شده در پنل بازشونده تنظیمات پیشرفته قرار گرفته‌اند.
- هشدار عمومی بودن رله‌های رایگان واضح‌تر شده است.

## محدودیت تأیید
این کنترل‌ها سیاست fail-closed را قبل از ساخت TUN اعمال می‌کنند؛ اما جای تست واقعی نشت DNS/IPv6 روی دستگاه را نمی‌گیرند. تا موفقیت CI روی آخرین commit و تست عملی Samsung Galaxy A15 / Android 16، این نسخه آماده انتشار یا اتصال تأییدشده محسوب نمی‌شود.
