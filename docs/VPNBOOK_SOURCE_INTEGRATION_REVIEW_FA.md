# بررسی فنی منبع دوم VPNBook برای راه‌یاب

تاریخ بررسی: 2026-11-05

## نتیجه

VPNBook یک منبع بالقوه برای افزودن سرور WireGuard و OpenVPN است، اما در وضعیت فعلی نباید ادعا کنیم که دریافت خودکار و بدون دخالت کاربرِ پیکربندی WireGuard آن قابل اتکا است.

### امکانات تأییدشده در صفحات رسمی

- صفحه وضعیت سرورها: https://static.vpnbook.com/status
- صفحه تولید WireGuard: https://static.vpnbook.com/freevpn/wireguard-vpn
- صفحه رسمی معرفی سرویس: https://www.vpnbook.com/

صفحه وضعیت می‌گوید گزارش سرورها هر پنج دقیقه به‌روزرسانی می‌شود و بار نسبی سرورها را نشان می‌دهد. این داده برای پیش‌غربال‌گری مفید است، ولی «Online» بودن به معنی موفقیت اتصال از شبکه کاربر نیست. راه‌یاب باید پس از ساخت تونل، ترافیک HTTPS و تغییر IP خروجی را مستقل بررسی کند.

صفحه تولید WireGuard:
- سرور و پورت UDP را انتخاب می‌کند.
- پورت‌های اعلام‌شده: 443، 80، 123 و 25018.
- کاربر باید شرایط را بپذیرد و مرحله بررسی/تأیید صفحه را کامل کند.
- فایل پیکربندی حاوی کلید خصوصی است.
- صفحه اختصاصی تولید، اعتبار پیکربندی را 7 روز اعلام می‌کند و استفاده هم‌زمان روی یک دستگاه را مجاز می‌داند.
- صفحه اصلی VPNBook در خبر قدیمی‌تر از نشست‌های 48 ساعته WireGuard هم نام برده است؛ بنابراین مدت اعتبار باید هنگام تولید و از خود سرویس دوباره تأیید شود، نه اینکه در برنامه ثابت فرض شود.

## تصمیم پیاده‌سازی

1. هیچ CAPTCHA، کنترل ضدربات یا مرحله تأیید کاربر دور زده نشود.
2. تا وقتی API رسمی و پایدار برای دریافت وضعیت/تولید پیکربندی مستند نشده، از وابستگی به endpointهای حدسی یا استخراج کلید از صفحه استفاده نشود.
3. مسیر امن اولیه: راه‌یاب صفحه رسمی تولید را باز کند؛ کاربر پس از انتخاب سرور و پورت و تکمیل تأیید، فایل WireGuard را به راه‌یاب وارد کند. سپس برنامه آن را اعتبارسنجی و مانند سایر نامزدها با تونل واقعی آزمایش کند.
4. اگر در آینده رابط رسمی قابل اتکایی برای وضعیت سرورها در دسترس بود، فقط برای مرتب‌سازی اولیه استفاده شود؛ انتخاب نهایی بر اساس handshake، HTTPS واقعی، تغییر IP، پایداری و سنجش داخل تونل باشد.
5. فایل کانفیگ WireGuard و private key هرگز وارد گزارش تشخیصی، لاگ، Analytics یا مخزن Git نشود. گزارش فقط شناسه منبع، زمان انقضا (اگر قابل تشخیص باشد)، نتیجه آزمون و خطای پالایش‌شده را ثبت کند.
6. VPNBook به‌عنوان سرویس رایگان ثالث معرفی شود، نه سرویس ناشناس/بدون ثبت اطلاعات. پیش از اتصال، هشدار حریم خصوصی و محدودیت‌های سرویس نمایش داده شود.
